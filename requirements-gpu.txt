# Extra stack for the shared Lightning GPU Studio (D-036), on top of requirements.txt.
# Kept separate so CI and the Apple Silicon bootstrap never pull PyTorch or VGGT (R-01).
#
# PyTorch is deliberately NOT listed: the Studio already ships a CUDA build (2.8.0+cu128 when
# F-05/F-07 were verified) and reinstalling it from PyPI could replace it with a mismatched one.
#
# numpy stays on 1.26.x in requirements.txt because VGGT declares `numpy<2`.
#
# VGGT is not published on PyPI, so it is pinned to a specific upstream commit. Bump the commit
# deliberately and re-run R-01 when you do. Model weights are downloaded from Hugging Face at first
# run, never committed (AGENTS.md) — set HF_HOME to a Teamspace Drive folder so they survive
# Studio recreation (D-036).
