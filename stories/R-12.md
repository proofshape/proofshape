## Notes and decisions

- PyCOLMAP 4.2.0 is used through the CUDA 12 package on the shared Lightning T4.
- COLMAP feature extraction imports phone GPS pose priors when present. R-12 clears those priors
  before writing R-02 board-derived Cartesian camera-position priors, so GPS and board coordinates
  are never mixed.
- COLMAP geometric depth has no VGGT-style learned confidence value. The common `depth_conf`
  output therefore stores a binary validity mask (1 = finite positive geometric depth, 0 =
  invalid/missing) and `run.json` records that meaning explicitly.
- An 8-frame real `s-04` production-path run succeeded end to end and wrote all four common
  artifacts. Measured wall clock was 303.866 s; PatchMatch dominated at 258.638 s.
- The full 30-frame `s-04` run produced a valid explicit refusal: COLMAP registered 28/30 input
  frames, with 29 board priors and 8,793 sparse points, so R-12 refused to fabricate depth/poses
  for the two missing frames. Measured wall clock was 73.787 s. This satisfies the story's
  acceptance criterion that a refusal is a valid, useful recorded result.
- The shared selector now reports that outcome as `RECON RUN: REFUSED`, not `PASS`.
