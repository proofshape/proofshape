## Why this exists

Batch mode retains exactly one decision — whether to ask for more photographs, and where. Without this, generative completion has no consumer in batch mode, so cutting interactive mode would strand it (D-002 as amended).

## Acceptance criteria

- After the first batch reconstruction, K completions run over the segmented mesh and produce a disagreement map.
- Where disagreement is high over a region the inspection spec marks critical, the system requests a targeted second batch and names the positions.
- Positions come from the existing next-view scorer fed the disagreement map, not raw coverage.
- The verdict path is untouched: completed surface stays labelled Inferred and excluded from deviation (D-005, D-006).
