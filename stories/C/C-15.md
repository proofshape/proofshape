## Why this exists

The report is the one page a buyer reads: "verdict, heatmap, 3D viewer, reference tier and scale
agreement, Observed fraction of each critical region, Unverifiable features, session ID and
timestamps" (proposal §7.5). The manual lists it as Planned (§8.3). Nothing in `capture/` calls
`getVerdict` yet. The contract's `reason_codes` exist "for the report page to explain in plain
language", and nothing does.

## Acceptance criteria

- **Client, types and mock.**
  - A `getVerdict` client and `Verdict`, `Region` and `VerdictResult` types, kept by hand like
    `src/types.ts`.
  - The stub gains a `/verdict` route that serves the contract's examples: Pass
    (`getVerdict.response-200.json`), Rescan (`…-200-rescan-unobserved.json`) and the 404
    `no_cad_uploaded`.
  - There is no Fail example in `contracts/examples`. Add one as a stub fixture under
    `capture/stub/fixtures` until a D-031 request adds it to the contract.
- **The page.** `report.html?session=<id>`, linked from the supplier's result, shows:
  - **the verdict,** with manual §8.2's "What to do" for it;
  - **every reason code in plain language.** A code with no description yet is shown verbatim,
    never hidden;
  - **each region:** its name, its provenance, its deviation in mm only where it is Observed ("—",
    not 0, anywhere else), and whether it counts toward the verdict;
  - **orientation ambiguity,** with the order's placement note when there is one (R-34, C-16);
  - **the reconstruction summary:** the reference used; metric, or "No dimensional claims"; the
    Observed fraction; and scale agreement, shown as "not checked" when the field is absent,
    which is every session today;
  - **the session id, and C-14's heatmap.**

  A 404 `no_cad_uploaded` reads "No CAD on this order: model only" (D-004), not as an error.
- **Print to PDF.** The browser's Save as PDF gives one page from a print stylesheet, with the
  heatmap as an image. Snapshot the canvas on `beforeprint`, because a WebGL canvas can print
  blank.
- **Templated text only.**
  - No tolerance, accuracy or σ_floor that the study hasn't measured (D-003).
  - No LLM. A-09's narrative gets a marked slot and nothing more.
