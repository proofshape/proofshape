## Acceptance criteria

- Every pull request runs ruff lint and format check on Python, `tsc --noEmit` and eslint on TypeScript.
- Whole run finishes in under two minutes.
- A pull request with a lint error is blocked from merging.

## Notes and decisions

Added `.github/workflows/python-ci.yml` for pull requests. The job runs Ruff lint and format
checks on Python and has a two-minute timeout. The TypeScript workflow is being delivered as a
separate pull request so each CI lane can be reviewed and merged independently.

Manual check: open a pull request with a deliberately failing Ruff check and confirm the CI
job fails; restore the check and confirm the job passes. GitHub branch protection must use the
workflow's check name before a lint failure can block merging.

Delivered as two pull requests so each CI lane could be reviewed and merged independently: #11
(Python — Ruff lint and format) and #12 (TypeScript — `tsc --noEmit` and ESLint, conditional on
`package.json` existing). Both merged 2026-09-14. Acceptance criterion 3 ("a pull request with a
lint error is blocked from merging") wasn't actually true until a follow-up step after both
merged: `required_status_checks` on `main`'s branch protection registered the `ruff` and
`typescript` check contexts — an admin-only setting neither PR's diff could express on its own.
Done same day.
