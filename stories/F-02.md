## Notes and decisions

The six top-level directories exist, each with its own `README.md` (needed anyway since git
does not track empty directories, and it's a natural place for run instructions to live next to
the code they describe).

For the Python packaging, only `recon/` is registered as an installed package
(`[tool.setuptools.packages.find]` with `include = ["recon*"]`). `inspect/` deliberately is
not: its name collides with Python's own standard-library `inspect` module, and installing it
as a top-level package on `sys.path` would shadow that module for the whole environment —
verified by installing both ways in a scratch venv and confirming `import inspect` resolves to
our package, not the stdlib, when `inspect/` carries an `__init__.py` and is included. Recorded
as D-025. This only blocks I-01 on picking an import name later; it does not block anything in
this story, since `recon/` is what the chain (F-02 → F-07 → R-01 → …) actually needs first.

Verified `pip install -e .` from a clean venv: installs cleanly, `import recon` works, and
`import inspect` still resolves to the standard library.

Scope note: `docs/sprint-plan.md` also mentions adding `CODEOWNERS` around the same time as repo
setup, but it isn't in this story's acceptance criteria (or F-01's), so it's left for whoever
picks that up rather than folded in here.
