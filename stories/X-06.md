## Acceptance criteria

- Board poses and reconstructed model poses are compared; disagreement flags the session.
- Gyro rotation between frames is compared against reconstruction rotation.
- The sheet's code is checked against an unused, order-bound link; a replayed session is rejected.
- A planar reconstruction — a photograph of a screen — fails the pose-agreement check.
