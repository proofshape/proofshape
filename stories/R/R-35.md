## Why this exists

R-30 moved every golden object's height cut to the fixed `DEFAULT_MIN_BOARD_CLEARANCE_MM` (2.0mm)
floor in `recon/part_segmentation.py::measure_board_surface`. That fixed board-skin false-Observed
faces on four of five golden objects, but R-30's own completion record flagged the fifth: s-02's
post-correction board noise (`residual_sigma_mm` 0.58mm, s-03 close behind at 0.57mm) leaves that
fixed floor at only about 3.4 sigma there, thin enough for real above-plane board noise to cross it
and get kept as part/skin instead of excluded as board. R-30 explicitly punted this ("a
sigma-relative cut is a candidate for R-33 or a later story, not this one") and it was never picked
up inside R-33, which turned out to be a different, unrelated investigation (marching-cubes wall
fabrication). Filed as #292 while closing out R-33. This story is that later story.

The fix: the floor should also scale with the board's own measured noise, not stay purely fixed —
`residual_sigma_mm` is already computed in the same function and already a `BoardSurface` field, so
no new plumbing is needed to use it.

This is independent of D-060, not a revision of it: D-060 governs the layer-top *search* (why
`main`'s plain whole-footprint histogram replaced three regressed per-cell/connectivity attempts);
this story changes the *floor* underneath that search, a separate term in the same `max(...)`.

## Acceptance criteria

- `measure_board_surface`'s measured path resolves its threshold as
  `max(min_clearance_mm, clearance_sigma_k * residual_sigma_mm, board_layer_top_mm)`, with
  `clearance_sigma_k` a new overridable keyword; the explicit `height_threshold_mm` override path
  is provably unchanged (existing test re-run, still passing with no edits).
- `DEFAULT_BOARD_CLEARANCE_SIGMA_K` is a measured value (D-003), chosen by sweeping candidate k
  against all five real golden objects' already-fused data and recording each one's board-skin
  Observed face share and `isolate_part` core stats — not picked arbitrarily. The sweep is recorded
  in this story's Notes and in a new decision, D-063.
- s-02's (and s-03's) board-skin Observed face share measurably improves at the chosen k, while
  s-01/s-04/s-05 do not regress.
- `isolate_part` (A-04's isolation stage, which reads `height_threshold_mm` straight off the
  returned `BoardSurface`) stays sane on all five objects at the chosen k.

## Tests

- a synthetic noisy-single-board-layer case (elevated `board_noise_mm`, no second layer) proving
  the resolved threshold rises above the fixed floor and tracks `clearance_sigma_k *
  residual_sigma_mm` -- the exact gap nothing today tests;
- a synthetic clean/low-noise board case proving the threshold is unaffected (stays at the fixed
  floor exactly) when sigma is small -- the sigma floor is a second, independent floor, not a
  replacement;
- the existing `test_second_board_layer_is_excluded_from_the_cut` and
  `test_measure_board_surface_explicit_height_threshold_skips_the_layer_search`, re-run unmodified
  to confirm the layer-top term still wins where it should and the override path is untouched;
- written alongside the formula change, not batched afterward.
