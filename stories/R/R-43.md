# R-43 · Measure edge loss and test a finer fusion grid

**Area:** recon · **Tier:** 1 · **Estimate:** 4 h
**Depends on:** R-32, R-33, R-37, R-38
**State:** Claimed
**Owner:** @dalwalyk

## Why this exists

D-078 reports 5.278 mm p95 absolute in-plane error on 11 caliper comparisons against the
aligned raw point cloud. R-32 also found that fusion moved some walls and narrowed the spread
of others. The demo team sees noisy, rounded edges. An offline comparison can separate
measurement bias from noise and show whether a finer grid preserves useful edge detail.

## Acceptance criteria

- Reuse saved depth maps, confidence, board poses and alignment for s-04 and s-05. Use the
  same physical edge identities across runs and compare with G-06 calipers. Report raw cloud,
  extracted mesh and final Observed mesh where each stage supports a comparable measurement.
  State which edges are unmeasurable and why.
- Run fusion at 2.0, 1.5 and 1.0 mm voxel widths with the 8 mm baseline truncation fixed.
  Keep the other settings fixed. Compare signed edge error, absolute error, wall spread,
  Observed coverage and fusion time. Report counts per stage and per configuration so losing
  a hard-to-measure edge cannot make a configuration look more accurate.
- Keep the experiment off the live capture path. Report which setting, if any, reduces
  errors on like-for-like Observed edges. A result on these two parts is a screening result.
  A deployment or a sub-3 mm accuracy claim needs independent calipered parts and repeat
  captures. The verdict continues to use Observed evidence only.

The metadata and primary measurements are from @TabeenRaoof's first review of #428. Supply

different inputs. The [R-32 input checksums](../../fixtures/r43-r32-inputs.sha256) match the
copy used on both members’ machines. From the checkout root with the project Python environment
active, verify the downloaded files and run the fusion sweep.

```bash
: "${R32_ROOT:?Set R32_ROOT to the downloaded runs/r32-runs directory}"
export R32_ROOT
R43_CHECKSUMS="$PWD/fixtures/r43-r32-inputs.sha256"
(cd "$R32_ROOT" && shasum -a 256 -c "$R43_CHECKSUMS") || exit 1
mkdir -p proofshape-data/r43
export SWEEP_DIR="$(mktemp -d "$PWD/proofshape-data/r43/shared-sweep.XXXXXX")"
printf '%s\n' "$SWEEP_DIR"
PYTHONPATH="$PWD:$PWD/inspect" python - <<'PYRUN'
import json
import os
import statistics
import time
from pathlib import Path

from recon import mesh_cleanup, provenance, tsdf_fusion, uncertainty
from recon.cad_size_check import build_report, write_report

runs = Path(os.environ["R32_ROOT"])
sweep = Path(os.environ["SWEEP_DIR"])
features = json.loads(Path("fixtures/caliper_g-06.json").read_text())["features"]
cad_names = {
    "s-04": "s04_triangular_prism_60-26-65x30mm.stl",
    "s-05": "s05_rect_prism_30x30x60mm.stl",
}
sessions = {
    "s-04": "s-04-all-vggt/sess_e8d97b4c3a37",
    "s-05": "s-05-all-vggt/sess_4ab66282d7d7",
}
for sample, session in sessions.items():
    artifacts = runs / session / "artifacts"
    source = artifacts / "reconstruction"
    alignment = source / "metric_alignment.json"
    board_pose = artifacts / "board_pose"
    name = cad_names[sample]
    cad_path = Path("fixtures/reference_cad") / name
    for voxel in (2.0, 1.5, 1.0):
        output = sweep / sample / str(voxel)
        fusion = output / "fusion"
        started = time.perf_counter()
        tsdf_fusion.fuse_run(
            source, alignment, fusion, voxel_size_mm=voxel, truncation_mm=8.0
        )
        fusion_s = time.perf_counter() - started
        model = output / "mesh_clean.glb"
        mesh_cleanup.cleanup_run(fusion / "mesh.ply", model)
        provenance.provenance_run(
            model, source, alignment, output / "provenance", fusion_dir=fusion
        )
        labels = uncertainty.uncertainty_run(output / "provenance", output / "uncertainty")
        report = build_report(
            source,
            board_pose,
            cad_path,
            observed_glb=output / "uncertainty/mesh_uncertainty.glb",
            caliper_features=[feature for feature in features if feature["object"] == sample],
        )
        write_report(output / "sizes.json", report)
        profiles = report["prism"]["fused_observed"]["wall_profiles"]
        spreads = [
            (wall["edge_index"], wall["cad_length_mm"], wall["thickness_median_mm"])
            for wall in profiles
        ]
        print(sample, voxel, fusion_s, labels["observed_fraction"], spreads)
        print("median wall spread:", statistics.median(wall[2] for wall in spreads))
PYRUN
```

The checker reuses the raw cloud's fitted wall pose for every grid of a capture. Only vertices
on fully Observed faces enter the final wall profiles. For each wall, `thickness_median_mm`
is the median of its p90−p10 signed perpendicular spread across populated height bands.
The aggregate below is the median of those per-wall values. Coverage is the area of fully
Observed faces divided by total mesh area after uncertainty labelling.

## Pose-checked edge replay (2026-11-21)

The replay used the same two hash-verified shared sessions, with fusion from `4c670ad` and
8 mm truncation. [Tabeen’s clean-checkout replay](https://github.com/proofshape/proofshape/pull/433#pullrequestreview-6009609805)
reproduced the original fixed-pose values and showed that their wall assignments mixed
neighbouring sides. Those values are superseded by the refit here.

Run this after the fusion sweep above. The JSON gives the seed and fitted board-frame directions,
the angle of each first and final fit relative to its seed, signed errors and counts.

```bash
PYTHONPATH="$PWD:$PWD/inspect" python -m scripts.measure_r43_edges \
  --input-root "$R32_ROOT" --sweep-dir "$SWEEP_DIR" \
  --output "$SWEEP_DIR/refit.json" --filter-diagnostic
```

The replay applies the measured G-06 board pitch to the aligned raw cloud and each mesh. It
uses the raw fitted board plane, height and wall seeds for all stages. In the 30–70% height band,
points start on their nearest seed line within the larger of 5 mm and three times the raw fit
residual. The runner robustly fits the wall lines and reassigns points until their labels stop
changing, keeping the edge indices fixed. When an assignment cycles, it excludes and counts
only the points that changed labels within that cycle. This removed one sample each on s-04’s
1.0 mm cleaned mesh and s-05’s 2.0 mm cleaned mesh. Each line needs at least five points, and a
length needs both adjacent corners. A stage that fails to converge stops the replay with an error.

### Component filter and coverage

Tabeen traced the old s-05 edge shift to 14 removed vertices in the height band and distance
gate. In the fixed assignment, one edge moved about 3.23 mm shorter and its opposite about
3.19 mm longer. With the refit, that first edge moves from 4.77 mm short before component removal
to 4.58 mm short immediately after and 4.63 mm short in the final Observed selection.

Using the same extracted meshes, the replay ran cleanup, provenance and uncertainty with a
component-size fraction of 10%, 1%, and 0% (retain all). At 2.0 mm, all seven final Observed
edge errors were identical. At 1% s-04 still retained only the main component (its largest
fragment has 15 faces), so retaining all was the informative alternative there. On the finer
grids the largest change in any final Observed edge across filter settings was 0.18 mm, on s-04
at 1.0 mm. The experiment does not support loosening the filter.

The Observed area share drops at 1.0 mm because total area grows faster. Absolute Observed area
increases across the three grids, from 3,888 to 4,052 to 4,225 mm² on s-04 and from 6,450 to
6,742 to 6,912 mm² on s-05. The wall-spread values above use the refitted directions in the same
height bands as the initial comparison.
