## Why this exists

Inspection is a comparison, and the comparison starts by putting the reconstructed
model onto the CAD. The method is settled (proposal §7.1): "Global registration (FPFH
features + RANSAC), then robust point-to-plane ICP with a Tukey loss", with "Scale
... fixed to 1 in the fit because the model is already metric; the free-scale residual is
computed separately as a check on substitution." This story is the first half.

## Acceptance criteria

- `inspection.registration.global_register(model, cad)` samples the CAD surface with
  normals (Open3D `sample_points_uniformly`), computes FPFH features, runs
  `registration_ransac_based_on_feature_matching` with scale fixed to 1, and absorbs the
  frame flip (CAD is z-up from z = 0; the model's base is at z = 0 with its body at
  z < 0).
- It returns a **list of distinct candidate poses**, each with Open3D's `fitness` and
  `inlier_rmse`: the RANSAC result, plus poses enumerated by yaw about the board normal
  (the part rests on the board, so the free pose is yaw and an xy shift; see
  `recon.cad_size_check._fit_rigid_2d` for the same idea), plus reseeded RANSAC runs if
  fewer than N distinct poses result. Open3D's RANSAC returns one result; this is how
  I-05 gets a runner-up to compare.
- The free-scale residual (proposal §7.1: "computed separately as a check on substitution") is
  a **separate two-stage ICP using only Observed model evidence**. A rigid point-to-point ICP
  first refines the inverse of the Observed-only yaw/xy seed with source = Observed model and
  target = a dense CAD surface; a second Open3D `registration_icp` pass uses
  `TransformationEstimationPointToPoint(with_scaling=True)`. The reverse direction is
  deliberate: every Observed model point has a CAD counterpart, while CAD -> partial model
  biases scale small when a CAD patch is hidden. If the model->CAD scale is `s`, the reported
  residual is `1/s - 1`, preserving R-05/D-039's sign convention (+0.03 means the model came
  out 3% larger than the design). Planar-only Observed evidence returns `None` rather than
  pretending to establish 3-D scale. The returned pose candidates themselves remain rigid.
  I-04 recomputes the diagnostic after refinement.
- **Tests, written with the code**, on I-01 output for s-04 and s-05: the best candidate
  recovers the sidecar transform to within a stated multiple of the injected σ; noisy
  true-size residuals stay near 0; noisy +3% and +5% scale substitutions preserve their
  sign/magnitude; the residual is invariant to vertex ordering; and a symmetric s-05 run
  retains multiple distinct yaw basins for I-05.

## Notes and decisions

- Voxel size and FPFH radius are parameters relative to the part's extent, with stated
  defaults. They are the likeliest cause of this story running over its estimate.
- Open3D 0.18.0 is already pinned (D-047); no new dependency.
- No tolerance appears here. Whether a residual is acceptable is R-05's 2% rule for
  scale (D-007) and, for shape, I-06/I-07's job once G-04 has measured σ_floor.
- Review found that support/extreme-point correspondences were unsafe on planar faces:
  ties made the residual depend on vertex order and could reverse the sign under noise.
  Similarity ICP replaced that method; the cube permutation and noisy s-04/s-05 cases pin
  the fix.
- **Planar-evidence gate:** the free-scale diagnostic requires the CAD points matched by the
  rigid Observed-model -> CAD pass to span at least 2% as much in their weakest principal axis as
  in their strongest. This 0.02 ratio is a declared algorithmic assumption, not a measured
  inspection tolerance. The gate is computed on noise-free CAD targets rather than noisy observed
  points so observation noise cannot manufacture fake 3-D scale evidence from a single visible
  plane.
- **Hard-rule boundary:** provenance is preserved when the reconstructed model supplies it.
  The returned global pose candidates remain I-03's geometric hypotheses, but the
  `free_scale_residual` is computed through a separate yaw/xy seed plus similarity ICP using
  **fully Observed model faces only**. Unobserved or Inferred geometry cannot choose the
  diagnostic pose, correspondence threshold or scale. If model provenance is missing, or no
  fully Observed face exists, `free_scale_residual` is `None` rather than fabricated evidence.
  Tests cover missing provenance, all-Unobserved/all-Inferred models, large perturbations
  applied only to hidden geometry, several noisy hidden-patch seeds, an Unobserved board-contact
  face, and planar-only evidence returning `None`.
