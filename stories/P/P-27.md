## Why this exists

By 2026-10-23, 69 stories were Done and nobody had looked back across all of them since P-14's
audit of the R stories. A review of every Done story against `main` found real defects in code
that had passed review: one weakens the hard rule (unseen surface can be labelled Observed),
others give wrong numbers to the supplier or delete real geometry. The bugs were filed as issues
#178–#201. Issues on their own have no owner, no claim and no hours, so this story turns them
into stories one person can pick up.

## Acceptance criteria

- The review's code bugs are GitHub issues, each verified against `main` with file and line links
  (#178–#201).
- The ten follow-up stories listed under *Scope* have story files and rows in a new "Review
  follow-ups" section of `stories/README.md`, each naming the issues it closes, and
  `scripts/check_story_states.py` passes on them.
- Issues that need a team decision before anyone fixes them are listed in that section and get no
  story yet.

## Scope

The ten stories, by topic. They are the content of the second criterion, not separate criteria.

- **R-25** Provenance occlusion: facing test, σ window, `observed_fraction` from final labels
  (#178, #185, #179).
- **R-26** Segmentation keeps flat parts; the height override bypasses the layer search (#180).
- **R-27** Mesh cleanup and the Poisson fallback: winding, components, size limit, oriented
  normals (#183, #184).
- **R-28** Portrait-safe VGGT intrinsics rescale and correct board metadata (#182, #188).
- **R-29** Contract-shaped validation errors and an Inferred-aware hard-rule test (#186 in part,
  #187).
- **C-19** The viewer says when a model has no provenance; the mock matches the service (#192,
  #193).
- **C-20** Capture gate and orbit maths: heading wrap, roll, gate order (#189, #190, #191).
- **F-08** Fixture and image safety: downloader verification, case-insensitive photo ignores,
  image path filters (#196, #197, #198).
- **I-12** Synthetic-generator tests that pin noise, seed and the board frame (#199).
- **P-28** Process tooling: checker exit codes, the decision-number snippet, a portable deck build
  (#194, #195, #201).

Waiting on a decision, no story: #181 (changes D-039's formula), #200 (Python version vs the
open3d pin, D-047), and the internal-failure error code half of #186 (a contract change, D-031).
