2026-09-21: Implementation. `scripts/bootstrap_dev_env.sh` is the one command: it picks
`python3.11` if present, else falls back to any `python3` that reports `>= 3.11` (refusing
otherwise with an explicit message, per the no-silent-failures rule), creates `.venv` if it
doesn't exist, and installs the project editable plus every pinned dependency in
`requirements.txt`. Verified locally on Apple Silicon (macOS, Python 3.11.16) from a fresh
`.venv`: bootstrap, `pytest -q` (15 passed), `ruff check .`, and `ruff format --check .` all
clean.

`ruff` was added to `requirements.txt` and to the `dev` extra in `pyproject.toml` — it wasn't
there originally, but AGENTS_START_HERE.md's pre-PR checklist requires `ruff check .` and
`ruff format --check .` every session, so a "reproducible dev environment" that doesn't include
the tool needed for that checklist isn't actually complete. Pinned to `0.16.8` (current at time
of writing) for reproducibility; note that `.github/workflows/python-ci.yml` installs ruff
unpinned, so CI and local can drift apart over time — out of scope for this story, flagging for
whoever next touches F-04/CI.

Not yet satisfied: acceptance criterion "verified by a second member from a clean checkout," and
running the bootstrap script on the actual shared GPU workspace (F-05) rather than just reasoning
that a POSIX bash script should behave the same there. Both need a second person and are part of
PR review, not something one person can self-certify.
