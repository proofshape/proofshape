## Acceptance criteria

- Compares printed board pitch, an optional typed caliper value, and the CAD registration residual.
- Flags the session when any two disagree by more than about 2%.
- Unit tested by injecting a disagreement.

2026-09-29: Implemented `check_scale_agreement` in `recon/scale_agreement.py`. The board pitch,
caliper reading, and CAD registration residual are different kinds of quantities (two lengths and
a fractional error), so all three are converted to a scale ratio relative to the nominal board
pitch before comparing — see D-039 for the full reasoning. Board pitch alone is rejected; at
least one of the caliper reading or CAD residual must also be supplied, matching `minItems: 2` on
`ScaleAgreement.sources_compared` in `contracts/openapi.yaml`. The CAD registration residual is
accepted as a plain optional float — CAD registration itself (`inspect/`) is Tier 2 and not built
yet, so this story only defines the shape that input takes once it exists, per D-039.

Unit tested by injecting disagreements per the acceptance criteria: an agreeing and a disagreeing
case for each optional source individually, a case where two agreeing sources don't mask a third
that disagrees (any *one* disagreeing pair is enough to flag, not all pairs), plus input
validation (non-positive/non-finite pitch or caliper reading, a CAD residual implying zero or
negative scale, board pitch supplied alone) and a configurable-threshold case. 13 new tests in
`tests/test_scale_agreement.py`; 115 total pass, ruff clean.
