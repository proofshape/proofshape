## Acceptance criteria

- Every pull request runs ruff lint and format check on Python, `tsc --noEmit` and eslint on TypeScript.
- Whole run finishes in under two minutes.
- A pull request with a lint error is blocked from merging.

## Notes and decisions

Python CI merged in PR #11 and TypeScript CI merged in PR #12. The workflow files themselves
cover Ruff lint/format and conditional TypeScript/ESLint checks, but this story is not Done yet.
The third acceptance criterion requires a failing lint check to block a merge, and `main`'s
required-status-check list is currently empty. Until branch protection requires the CI check
contexts, the workflows report failures but do not enforce the merge gate.

Owner is recorded as `@dalwalyk`, matching the GitHub account that authored PRs #11 and #12.
Keep the story Claimed until the required status checks are configured and the deliberate
failing-lint manual check has proved the merge is actually blocked.

Manual check to finish the story: configure the required CI check contexts on `main`, open a
small test PR with a deliberate Ruff failure and confirm GitHub blocks merging; restore the
failure and confirm the check passes. Record the real total hours across PRs #11 and #12 when
closing the story.
