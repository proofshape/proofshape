## Why this exists

σ_floor is defined per reference tier, not once overall (glossary). G-04 measured it for the
board reference only and recorded explicitly that its result "doesn't yet hold for app capture
or for the sheet and card references (G-10)." The verdict logic can't set tolerances for an order
placed on a sheet or card reference until this exists (I-07, I-09), and nothing substitutes the
board figure for the other two tiers without measuring them — a reference with less printed
structure for registration to anchor on plausibly has a different, probably worse, noise floor.

## Acceptance criteria

- The method is G-04's own, applied to the sheet and card references in turn: per-feature error
  is reconstruction minus caliper truth, not minus CAD; scale error is separated from shape error
  by the similarity fit; mean and 95th-percentile error reported per reference; how σ_floor
  follows from each.
- The chain runs on real captures taken against the sheet reference and the card reference
  specifically (not the board), through the same extended `cad_size_check` G-04 built.
- Each result is recorded as a decision in `docs/decisions.md`, with its own conditions (as
  G-04's own entry does), and `docs/glossary.md`'s σ_floor entry is updated once both are
  measured, so it no longer says the sheet/card floors "follow" without a figure.
- If either floor comes out above 3 mm, that is reported as the result and the proposal's M3
  fallback applies, exactly as G-04's own acceptance criteria already state for the board
  reference — the method is not tuned until the number looks better.

## Tests

Written record, same as G-04: the measurement itself is a written check, any code extension
(if the sheet/card tiers need a different footprint or detection path) gets tests alongside it.

## Notes and decisions

- Depends on G-04 landing first since it is the same method, reused rather than redesigned.
- Whether the sheet and card references need their own capture fixtures, or can reuse G-08's
  existing set with a different reference substituted, is a real question for whoever claims
  this — not decided here.
