# fixtures

The golden capture set — several objects photographed on a printed reference board — lives
outside git, in cloud storage. This directory holds only the download script and its checksums,
never the photographs themselves (see `.gitignore` and `AGENTS.md`).

**`charuco_board.pdf`** is the exception: it's the calibration target itself, not captured data —
small, deterministic, and exactly what R-02/R-03 need to match. Print at 100% scale, never "fit
to page." Parameters (`DICT_5X5_250`, 8×6 squares, 20 mm/15 mm, non-legacy pattern) are recorded
in `docs/decisions.md` D-034, so this file can be regenerated byte-for-byte if it's ever lost;
it's committed anyway so nobody has to re-derive the settings or depend on a third-party
generator's UI staying the same.

Otherwise empty until F-06 adds the download script for the captured photos themselves.
