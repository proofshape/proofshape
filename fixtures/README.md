# fixtures — download script and checksums only

The golden capture set lives in cloud storage, not in git. Photographs are hundreds of megabytes
and git never forgets: one committed fixture bloats the repository permanently, even after deletion.

**This folder holds only** the download script and a checksum manifest. `.gitignore` blocks
everything else here.
